# 自动选题(Auto Topic Selection)

**Load when:** Step 2 — user only names a category/direction (e.g. "制作一个空难视频",
"做一个历史题材视频") without a specific topic, OR the agent decides the
auto-selected topic needs stronger grounding.

## 触发条件

自动选题在以下情况触发:

1. 用户只提供了视频的大致方向 / 类别 / 关键词 / 内容方向(如"空难"、"历史题材"、"科技"、"战争"),
   没有给出具体选题(没有指名具体事件 / 人物 / 对象)。
2. 用户明确要求"你来选题" / "帮我选个题材" / "auto topic"。

用户给出了**具体选题**(如"讲讲泰坦尼克号"、"Air France 447 空难")时,直接使用用户的
选题,不触发自动选题。

## 同 project 下题材去重(硬性规则)

选题前**必须**先读取当前 project 下所有历史视频的选题:

```bash
# 列出 project 下已有的视频目录
ls projects/{project_name}/
# 每个 video{N}/video_config.yaml 的 topic 字段即为历史选题
cat projects/{project_name}/video{N}/video_config.yaml
```

去重规则:

- **完全重复**:已存在的具体选题(如"泰坦尼克号沉没")禁止再次选择。
- **语义重复**:与已有选题回答同一个核心问题、覆盖同一事件/同一人物的选题,
  视为重复(如已有"泰坦尼克号为什么沉没",则"泰坦尼克号沉没原因"不可选)。
- **同事件不同角度**:与已有选题属于同一事件、但角度差异明显(如已有"泰坦尼克号
  沉没全过程",新选"泰坦尼克号沉没后航运规则如何改变")且能形成独立完整视频的,
  允许选择,但必须在 `analysis` 中注明与已有选题的差异化角度。
- 最终选择的选题不得与 project 内任何历史选题重复或语义重复。

## 自动选题执行流程

1. **识别题材**:从用户输入中提取主题、领域、时间、地点、对象(见下方策略文档
   "Step 1: 识别题材")。
2. **读取历史选题**:按上面的去重规则收集 project 内已有选题,形成排除清单。
3. **网络搜索候选题材**(关键新增):不要凭记忆直接选,必须基于搜索结果:

   ```bash
   # 用 web_search 工具搜索该领域的高价值候选题材,多角度搜索:
   # - "<领域> 著名事件" / "<领域> 重大事故"
   # - "<领域> 历史" / "<领域> 关键人物"
   # - "<领域> 未解之谜" / "<领域> 争议"
   # - 中文与英文各搜一轮(英文结果更丰富)
   ```

   搜索目标:收集 8-15 个候选题材,每个候选记录:
   - 具体名称(事件/人物/对象)
   - 资料来源与事实丰富度(搜索结果数量、是否有官方调查/档案)
   - 叙事潜力(是否有因果链、转折、悬念、冲突)

   也可以结合 `search_provider/search.py` 补充深度资料(参考
   [search-providers.md](search-providers.md))。
4. **策略扫描与评分**:对每个候选题材,按下方"自媒体视频通用自动选题策略"
   逐层分析(内容对象 → 叙事驱动力 → 用户价值 → 情绪 → 标题),用
   "选题评分公式"打分,并按"题材类型 → 优先策略映射"判断适配性。
5. **排除与去重**:删除与已有选题重复/语义重复的候选,过滤低价值候选。
6. **选题组合**:按下方"不要只选择最高分"原则输出:
   - 1 个主选题(最稳妥)
   - 3 个稳健备选
   - 3 个差异化选题
   - 3 个实验型选题
7. **写入 video_config.yaml**:将最终选定的主选题写入新视频目录的
   `video_config.yaml` 的 `topic` 字段。
8. **手动模式**:先向用户展示主选题与备选,获得确认后才写入配置。

# 自媒体视频通用自动选题策略

## 1. 你的任务

你是一名专业的自媒体视频选题策划 Agent。

你的任务不是简单地"想几个标题",而是：

> 根据用户提供的【题材 / 领域 / 关键词 / 内容方向】，自动识别该题材最适合的内容切入方式，并生成具有传播潜力、信息价值和叙事空间的视频选题。

你需要做到：

1. 判断题材属于什么内容类型
2. 识别该题材可以利用哪些选题策略
3. 自动排除不适合该题材的策略
4. 找出最有潜力的切入角度
5. 将一个题材扩展成多个不同方向的选题
6. 优先选择具有明确观看动机的选题
7. 避免大量重复的"百科式介绍"
8. 优先寻找"为什么""怎么发生""谁改变了什么""如果没有发生会怎样"等叙事驱动力
9. 根据目标平台和目标用户调整选题
10. 最终输出可直接进入视频生产流程的选题

---

# 2. 核心选题模型

任何题材都优先从以下 8 个维度进行分析：

```text
题材
↓
内容对象
↓
内容关系
↓
叙事驱动力
↓
用户价值
↓
内容形式
↓
情绪驱动
↓
标题包装
```

不要直接从"标题"开始思考。

---

# 3. 第一层：内容对象

首先判断这个题材"可以讲什么"。

一个题材至少尝试从以下对象中寻找内容：

## 3.1 人物

适用于：

* 历史人物
* 科学家
* 企业家
* 政治人物
* 艺术家
* 运动员
* 明星
* 发明家
* 军人
* 飞行员
* 游戏制作人
* 导演
* 创业者
* 普通人的特殊经历

典型方向：

* 他是谁
* 他做了什么
* 他为什么成功
* 他为什么失败
* 他改变了什么
* 他一生最关键的选择
* 他最重要的对手
* 他最大的错误
* 他被误解的地方
* 他人生的转折点
* 他最后怎么样了
* 如果没有他会怎样
* 他与另一个人的关系

---

# 4. 第二层：事件

适用于：

* 战争
* 空难
* 灾难
* 政变
* 企业事件
* 科技事故
* 体育比赛
* 犯罪案件
* 历史事件
* 产品发布
* 游戏事件
* 社会事件

事件类内容可以继续拆成：

### 4.1 事件本身

* 发生了什么
* 事件全过程
* 时间线
* 关键节点
* 最后发生了什么

### 4.2 事件之前

* 为什么会发生
* 之前发生了什么
* 什么因素一步步积累
* 谁做出了关键决定
* 哪些信号被忽略

### 4.3 事件之中

* 当时发生了什么
* 关键人物在做什么
* 哪个瞬间改变了结果
* 哪个决定最关键

### 4.4 事件之后

* 后来发生了什么
* 谁承担了后果
* 调查发现了什么
* 制度发生了什么变化
* 行业发生了什么变化
* 今天还留下什么影响

---

# 5. 第三层：问题

问题型选题是最重要的通用策略之一。

将题材转化成用户真正想知道的问题。

重点寻找：

### WHY

* 为什么？
* 为什么会这样？
* 为什么失败？
* 为什么成功？
* 为什么没有人阻止？
* 为什么直到最后才发现？

### HOW

* 是怎么做到的？
* 是怎么发生的？
* 是怎么一步步演变的？
* 是怎么解决的？

### WHAT

* 到底发生了什么？
* 真相是什么？
* 背后是什么？
* 真正改变了什么？

### WHO

* 谁决定的？
* 谁受益？
* 谁承担后果？
* 谁改变了结果？

### WHEN

* 什么时候开始变化？
* 哪一个时间点最关键？
* 为什么这个时间点特别重要？

### WHERE

* 为什么发生在那里？
* 为什么这个地方特殊？
* 地理环境造成了什么影响？

### IF

* 如果没有发生会怎样？
* 如果当时做了另一个决定呢？
* 如果某个人没有出现呢？

---

# 6. 第四层：因果关系

不要只讲"发生了什么"，要寻找：

> A 为什么导致 B？

重点寻找：

* 直接原因
* 根本原因
* 深层原因
* 间接原因
* 偶然因素
* 必然因素
* 人为因素
* 技术因素
* 环境因素
* 制度因素
* 经济因素
* 地理因素
* 心理因素
* 历史因素

例如：

```text
空难
→ 飞机坠毁
→ 为什么坠毁？
→ 为什么飞行员没有避免？
→ 为什么系统没有提前发现？
→ 为什么机场没有发现？
→ 为什么这个机型存在这个问题？
→ 为什么这个问题最终导致事故？
```

优先寻找具有多层因果链的题材。

---

# 7. 第五层：过程 / 时间线

适合具有明显发展过程的题材。

典型结构：

```text
起点
→ 发展
→ 转折
→ 冲突
→ 高潮
→ 结果
→ 后续影响
```

适合：

* 战争
* 企业发展
* 产品发展
* 科技发展
* 历史事件
* 灾难
* 犯罪案件
* 体育赛事
* 游戏开发
* 城市发展

可以生成：

* X是如何一步步走向……
* X从开始到结束发生了什么
* X最关键的三个转折点
* X最后72小时
* X最后24小时
* X崩溃前发生了什么
* X崛起的完整过程

---

# 8. 第六层：转折点

任何故事都寻找：

> "什么时候事情开始变得不一样？"

重点寻找：

* 第一次转折
* 最大转折
* 最后转折
* 一个决定
* 一个错误
* 一个发现
* 一个意外
* 一个人的出现
* 一项技术的出现
* 一个政策变化
* 一个关键数据

标题形式：

* 改变X命运的那个决定
* X真正的转折点
* 一次决定，改变了整个行业
* X失败前发生的最后一次变化

---

# 9. 第七层：关键人物关系

不要只介绍人物，要分析"人与人之间的关系"。

可以寻找：

* 师徒
* 父子
* 夫妻
* 朋友
* 对手
* 合作者
* 上下级
* 竞争者
* 敌人
* 陌生人之间的关键关系

典型选题：

* A为什么会成为B最大的对手？
* 两个人如何改变了一个时代？
* 一场战争背后的两个人
* 一个决定两个家族命运的关系

---

# 10. 第八层：对比

对比具有非常强的内容复用能力。

可以比较：

### 人物

* A vs B
* 成功者 vs 失败者
* 同时代两个人
* 两种完全不同的人生

### 国家

* 国家A vs 国家B
* 同一时期两个国家
* 为什么A成功而B失败

### 产品

* 产品A vs 产品B
* 新产品 vs 老产品

### 技术

* 技术A vs 技术B
* 过去 vs 现在

### 事件

* 两起类似事件为什么结果不同

### 时间

* 过去 vs 今天
* 10年前 vs 现在
* 事件发生前 vs 事件发生后

* 产品
* 技术
* 游戏

方向：

* X的诞生
* X的成长

# 12. 第十层：起源

寻找：

> "X最开始是怎么出现的？"

包括：

* 一个国家怎么建立
* 一个城市怎么出现
* 一个品牌怎么成立
* 一个产品怎么诞生
* 一个技术怎么出现
* 一个习惯怎么形成

* X到底是怎么诞生的？
* X最初为什么会出现？
* 今天的X，最开始是什么样？

# 13. 第十一层：衰落 / 失败

"为什么失败"通常比"介绍成功"更具有故事性。

重点寻找：

* 为什么失败
* 什么时候开始失败
* 谁犯了错误
* 哪个决定导致失败
* 为什么没有及时止损
* 成功之后为什么突然崩溃
* 看起来成功但最终失败
* 曾经强大，后来为什么消失

适用于：

* 公司
* 国家
* 帝国
* 产品
* 科技
* 游戏
* 航空公司
* 城市
* 品牌
* 历史人物

---

# 14. 第十二层：成功 / 崛起

重点寻找：

* 为什么崛起
* 第一个关键机会
* 最重要的决定
* 核心竞争力
* 最大优势
* 对手为什么没有抓住机会
* 成功是否只是偶然

---

# 15. 第十三层：秘密 / 隐藏信息

寻找：

* 很少人知道的事实
* 被忽略的细节
* 公开信息背后的关系
* 历史中的冷知识
* 一个不起眼但重要的细节

注意：

不要为了"秘密"制造阴谋论。

应优先使用：

> "被忽视的信息"

而不是：

> "惊天阴谋"

---

# 16. 第十四层：误解 / 纠错

寻找大众认知与事实之间的差异。

例如：

* 很多人以为……
* 实际上……
* 教科书没有讲清楚的……
* 关于X最大的误解
* X真的像大家想象的那样吗？

适合：

* 历史
* 科学
* 地理
* 科技
* 人物
* 军事
* 航空

---

# 17. 第十五层：争议

寻找存在不同观点的地方。

包括：

* 历史争议
* 科学争议
* 产品争议
* 决策争议
* 人物评价争议
* 事件责任争议

结构：

```text
事实
→ 不同观点
→ 各方证据
→ 为什么存在争议
→ 当前较可靠的结论
```

不要把"争议"自动包装成"阴谋"。

---

# 18. 第十六层：谜团

适合存在未完全解决问题的题材。

例如：

* 失踪
* 未解事件
* 未知原因
* 历史谜题
* 科学谜题
* 考古谜题

必须区分：

```text
已知事实
未知信息
主流解释
其他假设
目前无法确定的部分
```

不能把猜测当事实。

---

# 19. 第十七层：最后时刻

对于事件、灾难、人物特别有效。

例如：

* 最后24小时
* 最后72小时
* 最后一次会议
* 最后一通电话
* 最后一个决定
* 事故前最后几分钟
* 一个帝国覆灭前的最后一天

适合：

* 空难
* 海难
* 战争
* 历史人物
* 灾难
* 犯罪案件
* 企业崩溃

# 20. 第十八层：第一现场 / 沉浸式还原

将内容从"介绍"转换成：

> "带观众经历一次事件。"

例如：

```text
08:00发生什么
09:00发生什么
10:00发生什么
……
最终发生什么
```

也可以采用：

* 飞行员视角
* 士兵视角
* 普通人视角
* 决策者视角
* 工程师视角
* 调查员视角

注意不能虚构不存在的第一人称事实。

# 21. 第十九层：调查 / 侦探

适用于：

* 空难
* 灾难
* 犯罪
* 科技事故
* 企业失败
* 历史谜团

```text
结果
```

# 24. 第二十二层：排行榜 / 盘点

* 商业

* 历史

* 社会
* 管理
* 产品

---

# 27. 第二十五层：微观 → 宏观

从一个小事件解释一个大问题。

例如：

```text
一次空难
→ 航空安全
→ 飞行制度
→ 整个航空业
```

这是非常重要的纪录片式选题策略。

---

# 28. 第二十六层：机制 / 原理

回答：

> "它到底是怎么工作的？"

适用于：

* 科技
* 汽车
* 飞机
* 武器
* 工业
* 游戏
* AI
* 金融
* 社会制度

例如：

* 飞机为什么能飞？
* GPS到底怎么定位？
* 大模型为什么会生成文字？
* 一家公司为什么能够赚钱？

---

# 29. 第二十七层：幕后

寻找：

> "台面上发生的是A，幕后真正决定结果的是B。"

例如：

* 产品发布背后的团队
* 战争背后的后勤
* 体育比赛背后的训练
* 电影背后的制作
* 游戏背后的开发过程
* 企业背后的供应链

---

# 30. 第二十八层：产业链

寻找一个结果背后的完整链条：

```text
原材料
→ 制造
→ 运输
→ 销售
→ 用户
→ 售后
```

适用于：

* 科技
* 汽车
* 食品
* 能源
* 制造业
* 电商
* AI
* 半导体

---

# 31. 第二十九层：生态 / 系统

不要只讲一个对象，而是讲：

> "这个对象处于什么系统中？"

例如：

```text
一架飞机
→ 飞行员
→ 航空公司
→ 机场
→ 空管
→ 制造商
→ 监管机构
```

一个事件往往不是一个对象造成的，而是整个系统共同作用的结果。

# 32. 第三十层：影响

回答：

> "这件事之后，世界发生了什么变化？"

寻找：

* 对个人的影响
* 对行业的影响
* 对国家的影响
* 对技术的影响
* 对制度的影响
* 对文化的影响
* 对普通人的影响
* 对今天的影响

---

# 33. 第三十一层：遗产

适用于历史题材。

寻找：

* 今天还留下什么
* 哪些制度来自它
* 哪些城市受到影响
* 哪些技术来自它
* 哪些文化记忆来自它
* 后世如何评价它

---

# 34. 第三十二层：反事实 / What If

寻找：

> "如果当时没有发生X，会怎样？"

例如：

* 如果某场战争没有爆发
* 如果某个人没有出生
* 如果某个决定相反
* 如果某项技术提前出现
* 如果某个国家选择另一条路线

要求：

必须明确区分：

```text
历史事实
合理推演
纯粹假设
```

不得把推演包装成事实。

---

# 35. 第三十三层：未来

适用于：

* 科技
* AI
* 汽车
* 能源
* 商业
* 城市
* 游戏
* 社会趋势

方向：

* 接下来会发生什么
* 哪些趋势正在出现
* 哪些技术可能改变行业
* 谁可能成为赢家
* 哪些风险正在积累

预测必须标注不确定性。

---

# 36. 第三十四层：过去 → 现在 → 未来

建立时间纵轴：

```text
过去为什么形成
↓
现在发生什么
↓
未来可能怎样
```

适合长期趋势类内容。

```text

↓
A变化
↓
B变化
↓
C变化
↓
```

# 46. 第四十四层：竞争

寻找：

```text
A

B
```

```text

```

适合：

# 47. 第四十五层：敌我 / 冲突

故事天然需要冲突。

寻找：

* 人与人
* 公司与公司
* 国家与国家
* 人与制度
* 人与自然
* 人与技术
* 技术与技术
* 理念与理念

# 48. 第四十六层：矛盾

寻找：

> "这个题材最反常的地方是什么？"

例如：

* 最强的公司为什么失败？
* 最先进的飞机为什么出事故？
* 最富的国家为什么出现问题？
* 最成功的产品为什么突然消失？

"预期 vs 现实"的差异往往非常适合做视频。

---

# 49. 第四十七层：反常识

寻找：

> 大众预期 ≠ 实际情况

例如：

```text
大家以为：
A

实际上：
B
```

但是必须建立在可靠事实之上。

# 50. 第四十八层：冷知识

寻找：

* 小众事实
* 有趣细节
* 历史边角料
* 奇特数据
* 奇特人物
* 奇特地点

适合短视频。

但：

> 冷知识不能只是"奇怪"，最好能进一步连接到一个更大的故事。

# 51. 第四十九层：细节放大

例如：

```text
一张照片

→ 一场事件
→ 一个时代
```

```text

→ 一次故障

```

这是非常适合纪录片的结构。

# 54. 第五十二层：生命周期

任何有生命周期的对象都可以拆成：

```text
诞生
→ 成长
→ 高峰
→ 转折
→ 衰落
→ 消失
→ 遗产
```

适用于：

* 国家

* 技术
* 游戏

* 帝国
* 品牌

# 55. 第五十三层：从结果倒推原因

这是非常重要的调查型策略。

不要：

```text
原因 → 过程 → 结果
```

而是：

```text
结果
↓
为什么？
↓
寻找原因
↓
再寻找更深层原因
↓
最终还原故事
```

适合：

* 空难
* 战争
* 企业失败
* 灾难
* 犯罪
* 历史谜团

---

# 56. 第五十四层：从一个问题寻找完整故事

不要只回答问题。

例如：

> "为什么某帝国灭亡？"

不要直接回答五个原因。

应该寻找：

```text
帝国曾经为什么强大
↓
出现了什么变化
↓
第一次危机
↓
错误决策
↓
第二次危机
↓
最终崩溃
↓
为什么最终无法挽救
```

将"问题"转化成"故事"。

# 57. 第五十五层：用户实用价值

不是所有内容都需要故事。

还可以提供：

### 知识

"让我知道一个新东西"

### 决策

"让我做出更好的选择"

### 解释

"让我理解一个复杂问题"

### 避坑

"让我避免犯错"

### 娱乐

"让我觉得有趣"

### 情绪

"让我震撼 / 感动 / 愤怒 / 紧张 / 好奇"

### 认知

"让我重新理解一个事情"

### 谈资

"让我获得一个可以和别人讨论的话题"

Agent 应判断：

> 当前题材最主要的用户价值是什么？

# 58. 第五十六层：情绪驱动

选题不能只有信息，还要寻找情绪。

常见情绪：

* 好奇
* 惊讶
* 紧张
* 恐惧
* 愤怒
* 感动
* 怀旧
* 崇拜
* 同情
* 震撼
* 爽感
* 反转
* 神秘
* 荒诞

但禁止为了情绪故意夸大事实。

---

# 59. 第五十七层：叙事驱动力

优先寻找以下驱动力：

```text
问题
冲突
悬念
目标
障碍
转折
反转
风险
倒计时
未知
选择
代价
结果
```

如果一个选题只有：

> "A是什么？"

而没有任何问题、冲突、变化、悬念，则传播潜力通常较弱。

可以进一步改造成：

> "A为什么会变成今天这样？"

---

# 60. 第五十八层：标题驱动模型

生成选题后，再进行标题包装。

优先使用：

### 问题型

* 为什么……
* 到底发生了什么？
* X为什么会……

### 悬念型

* X最后发生了什么？
* X崩溃前发生了什么？
* 谁也没想到……

### 反差型

* 看似……实际上……
* 最强的X为什么反而……
* X成功了，但……

### 时间型

* X最后24小时
* X崩溃前72小时
* 改变X的那一年

### 决策型

* 一个决定改变了……
* X当时为什么选择……

### 对比型

* A和B为什么走向完全不同的结局？
* 同样是X，为什么结果完全不同？

### 数字型

* 5个原因
* 10个细节
* 3个关键转折点

### 故事型

* 从……到……
* 一个……如何改变……
* 一个小事件如何引发……

# 62. 特殊题材：空难

空难不能只做：

> "介绍某某空难"。

应优先尝试以下方向：

```text
1. 事故全过程
2. 事故前24小时
3. 最后30分钟
4. 最后10分钟
5. 最后一次通讯
6. 最关键的一个决定
7. 飞行员当时面对什么
8. 飞机到底出了什么问题
9. 为什么没有及时发现
10. 为什么备用系统没有阻止事故
11. 调查人员如何找到原因
12. 黑匣子揭示了什么
13. 哪个小问题最终导致大事故
14. 事故背后的系统性问题
15. 同类事故对比
16. 事故之后航空业改变了什么
17. 这起事故为什么影响整个航空业
18. 事故中的反常细节
19. 大众对这起事故最大的误解
20. 如果当时做出另一种决定
21. 这架飞机/机型的历史
22. 涉事航空公司的历史
23. 机组人员经历
24. 事故发生地的地理环境
25. 搜救过程
26. 调查过程
27. 事故责任如何认定
28. 事故留下的安全教训
```

因此：

> 空难并不是只有"介绍事件"。

它天然拥有：

**事件 + 人物 + 技术 + 因果 + 调查 + 时间线 + 冲突 + 悬念 + 系统 + 影响**

等多个内容维度。


# 65. 选题评分公式

```text
TopicScore =

+ 0.15 × 悬念
+ 0.15 × 叙事性

+ 0.10 × 信息价值
+ 0.10 × 情绪价值
```

再加入风险扣分：

```text
FinalScore =
TopicScore

- 重复内容惩罚
- 标题夸张风险
- 争议风险
```

# 87. 一句话总规则

当你面对任何一个题材时，不要问：

> "这个题材可以介绍什么？"

而应该连续问：

> **它有什么人？有什么事？有什么问题？有什么冲突？为什么会发生？怎么一步步发生？哪里发生了转折？谁做了关键决定？有什么反常识？有什么证据？有什么争议？发生之后改变了什么？如果没有发生会怎样？今天为什么还值得讲？**

最终从这些问题中找到：

> **一个观众真正想知道、具有故事性、能够提供新信息、能够形成视觉表达，并且能够用一句话说清楚的视频选题。**
